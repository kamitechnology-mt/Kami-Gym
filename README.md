# KamiGym

Benvenuto nel repository ufficiale di rilascio di **KamiGym**!

Qui puoi trovare l'ultimo file APK compilato e le relative informazioni di versione utilizzate dall'applicazione per gli aggiornamenti OTA automatici in-app.

## Installazione
1. Scarica il file `KamiGym.apk` da questo repository (o dalla sezione Releases).
2. Apri il file sul tuo dispositivo Android.
3. Se richiesto, abilita l'installazione da "Sorgenti Sconosciute" per il tuo browser o gestore file.
4. Completa l'installazione e avvia l'app!
